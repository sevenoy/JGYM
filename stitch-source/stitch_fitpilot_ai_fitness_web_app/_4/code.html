杠铃卧推

fitness_center 胸部 胸大肌 三头肌
layers
4 推荐组数
repeat
8-12 次 / 组
timer
90s 休息时间

info 动作说明

  1. 平躺在平凳上，双脚平放于地面，保持身体稳定，收紧核心。
  2. 双手以略宽于肩的距离正握杠铃，将杠铃从架上推起，手臂伸直置于胸部上方。
  3. 吸气，缓慢控制地将杠铃下放至胸部中段，感受胸肌的拉伸。
  4. 呼气，胸大肌发力将杠铃快速向上推起，恢复至起始位置，顶峰收缩。
warning

注意事项

  • 下放杠铃时务必控制速度，避免在胸部发生弹振借力。
  • 保持手腕中立直立，切勿过度向后弯折以免造成关节损伤。
  • 大重量训练时，强烈建议有保护者在场协助。
